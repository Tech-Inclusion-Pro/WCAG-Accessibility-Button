# OpenDyslexic font files

`OpenDyslexic-Regular.woff` and `OpenDyslexic-Bold.woff` are the
[OpenDyslexic](https://opendyslexic.org) typeface by Abbie Gonzalez,
licensed under the [SIL Open Font License 1.1](https://openfontlicense.org).
They are redistributed here unchanged so the widget's "Reading font" option
works offline, with no network requests.

Copy this folder next to any HTML page that uses the widget. If the files
are missing the widget still works — the OpenDyslexic option falls back to
Comic Sans MS / Verdana.
