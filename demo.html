WCAG Accessibility Button

A self-contained display-settings widget for any HTML page. Click the Display settings button (bottom right) and try every option on this page.

What to try

  • Text size — the whole page scales, up to 150%.
  • Text spacing — line height, letter, word, and paragraph spacing open up; "Widest" meets the WCAG 1.4.12 metrics.
  • Color — color-vision friendly, monochrome, and yellow-on-black high contrast palettes restyle this entire page.
  • Reading font — switches body text to OpenDyslexic.
  • Pointer — bigger or high-contrast cursors, plus an optional trail.
  • Motion — the square below spins; "Slow down" and "Stop" control it live.
  • Button position — pick a corner, drag the grip, or nudge it with arrow keys.

Animation test: this square is driven by the widget's --dur variable.

Keyboard support

Tab to the button and press Enter. Focus lands on the close button; Escape closes the panel and focus returns. Every control is a native radio or checkbox, so arrow keys work inside each group. Focus the grip and press the arrow keys (Shift for bigger steps) to move the panel without a mouse.

Nothing leaves this page

Your choices are saved in your own browser with localStorage. Reload the page — they persist. There are no network requests, no cookies, and no tracking of any kind.
